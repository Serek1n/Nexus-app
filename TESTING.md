# Проверка версии перед выпуском

Пройти на настоящем телефоне Android и компьютере с Windows. Каждый пункт:
что сделать → что должно получиться. Что-то не так — «Отчёт для поддержки»
(Настройки → О приложении) и прислать его вместе с номером пункта.

Совет: сначала выпустить сборку в ветку `beta` и включить у себя
«Бета-версии» — обычные пользователи её не получат.

## 1. Первый запуск (на чистой установке)
- [ ] Открыть Nexus → экран «VPN, который думает за вас» → «Начать».
- [ ] «Добавить подписку» → вставить ссылку → «Готово: серверов — N».
- [ ] Android: «Разрешить работу в фоне» и «Разрешить уведомления» открывают системные окна.
- [ ] «Пропустить» сразу ведёт на главную и больше экран не показывается.

## 2. Подписка
- [ ] Название, трафик, срок на карточке подписки совпадают с панелью 3x-ui.
- [ ] Потянуть список подписок вниз — подписка обновилась (время «только что»).
- [ ] Есть кнопка «Продлить»; нажатие открывает бота или личный кабинет.
- [ ] Подписка в формате sing-box или Clash добавляется так же, как обычная.

## 3. Подключение
- [ ] Каждый тип сервера (VLESS Reality, VLESS XHTTP, Hysteria2, WireGuard, если есть): подключается, задержка зелёная/жёлтая, сайты открываются.
- [ ] «Скорость» на главной — показывает число, не ошибку.
- [ ] Умный режим: Госуслуги/банк открываются, YouTube работает.
- [ ] Выключить Wi-Fi на 30 секунд и включить — Nexus переподключился сам.
- [ ] Маскировка соединения вкл → подключение работает (чуть дольше соединяется).
- [ ] Блокировка рекламы вкл → сайты открываются, рекламы меньше.
- [ ] Настройки → DNS: переключить Cloudflare → Google → Quad9 → AdGuard, каждый раз переподключиться — сайты открываются.
- [ ] Отметить 2–3 сервера звёздочкой → на главной под сервером полоса избранных; нажатие на чип переключает сервер (и переподключает, если VPN включён).

- [ ] Перезапустить Nexus → через ~10 с у серверов появились задержки сами.
- [ ] Подключиться по Wi-Fi, выключить Wi-Fi (перейти на мобильную сеть) → «Сеть сменилась — переподключаюсь…», связь вернулась за несколько секунд.
- [ ] Включить самолёт на минуту и выключить → «Нет сети — подключусь…», затем VPN поднимается сам.

- [ ] «Только заблокированное»: YouTube/Instagram/ChatGPT открываются, «IP для сайтов» на 2ip.ru — российский (сайт идёт напрямую).
- [ ] Маскировка «Быстрая» → подключение работает; если нет — «Надёжная» работает.
- [ ] Вставить ссылку `happ://add/<ваша подписка>` → подписка добавилась; повторно — не задвоилась.
- [ ] Подписка → ⋮ → «Запасные адреса» → сохранить https-адрес → сохраняется.

## 4. Режим «Авто»
- [ ] Включить → строка «Авто» на главной; через ~10 с — «Сейчас: <сервер> · N мс» (Android и Windows).
- [ ] В меню сервера «Не использовать в режиме «Авто»» → сервер с отметкой, «Авто» его больше не выбирает.
- [ ] Выбрать сервер вручную → «Режим «Авто» выключен».

## 5. Android
- [ ] Добавить плитку Nexus в шторку → нажатие подключает/отключает **без открытия** Nexus (после первого подключения из приложения).
- [ ] Виджет на рабочий стол → то же самое, надпись «Подключено/Отключено» меняется.
- [ ] Закрыть Nexus из списка недавних, VPN включить плиткой, открыть Nexus → он видит подключение.
- [ ] Скопировать ключ сервера → через 2 минуты буфер пуст; в подсказках клавиатуры ключ не виден (Android 13+).
- [ ] Статистика трафика: после перезапуска Nexus при работающем VPN цифры не удваиваются.
- [ ] **Постоянная VPN:** Настройки Android → Сеть → VPN → ⚙ у Nexus → «Постоянная VPN» + «Блокировать соединения без VPN». Подключиться один раз из Nexus, перезагрузить телефон, Nexus не открывать → после разблокировки VPN поднимается сам, интернет есть.

## 6. Windows
- [ ] Системный прокси: браузер работает через Nexus, после отключения прокси Windows возвращается как был.
- [ ] Режим TUN (перезапуск от администратора) → Telegram и игры через VPN.
- [ ] «Программы»: steam.exe в «Всегда напрямую» → Steam качает мимо VPN (в TUN).
- [ ] «SOCKS-прокси с паролем» вкл → «Подключить Telegram» → Telegram работает.
- [ ] Меню трея: «Режим «Авто»», выбор сервера, «Выход».

## 6½. Новое в 2.4.0
- [ ] Настройки → «Вход по PIN-коду» → задать PIN → свернуть Nexus на 2 минуты → открыть → экран PIN. Неверный PIN 5 раз — пауза 30 с. «Забыли PIN-код?» → «Стереть всё» сбрасывает приложение.
- [ ] Оформление «Светлая» и «Как в системе» — всё читается, кнопки видны.
- [ ] Карта на главной: точка в стране сервера, при подключении «дышит».
- [ ] Android: долгое нажатие на значок Nexus → три ярлыка, «Подключить» подключает.
- [ ] Android: «Поделиться (QR)» → скриншот не делается.
- [ ] Android TV (если есть): Nexus в меню; пультом видно, что выбрано (фиолетовая подсветка/кольцо у кнопки подключения), OK подключает.
- [ ] PIN включён (Android 13+): в списке недавних приложений у Nexus пустое окно, а не серверы.
- [ ] «Только заблокированное»: открывается заблокированный сайт не из популярных (например, rutracker.org или linkedin.com).
- [ ] Windows: Ctrl+Alt+N подключает/отключает при свёрнутом Nexus.
- [ ] Windows: «Серверы» → кнопка скорости всех → у серверов «N Мбит/с».
- [ ] Windows: включить TUN (перезапуск от администратора) → подключается; в журнале «ядро запускается из защищённой папки».

## 7. Данные и язык
- [ ] Настройки → «Проверка связи» без VPN: интернет, DNS, Госуслуги, сервер подписки, сервер — зелёные; «Сайты через VPN — подключитесь, чтобы проверить».
- [ ] То же при подключённом VPN: Google, YouTube, Instagram, Telegram, Discord — зелёные; «IP для сайтов» — страна сервера. Кнопка копирования работает, результат есть в «Отчёте для поддержки».
- [ ] Резервная копия → пароль (от 8 символов) → скопировать строку → «Сбросить всё» → «Добавить» → вставить → пароль → всё вернулось.
- [ ] Язык English → интерфейс, «Что нового» и плитка на английском.
- [ ] Отчёт для поддержки: в тексте нет vless://, UUID и путей ссылок подписок.

## 8. Обновление
- [ ] Открыть ссылку `nexus://add/http://example.com/sub` → в окне жёлтое предупреждение «Ссылка без шифрования»; `nexus://add/vless://…` → видно «VLESS · адрес сервера».
- [ ] Быстро нажать «Подключить» 3 раза → одно подключение, в журнале один «Запуск ядра».
- [ ] Поставить прошлую версию → карточка «Доступно обновление» → «Установить» → встала поверх, подписки на месте.
- [ ] «Откатить версию» показывает список прошлых версий.
